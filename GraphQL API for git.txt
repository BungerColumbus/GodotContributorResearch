api graphql -f query='
query($login: String!, $from: DateTime!, $to: DateTime!) {
  user(login: $login) {
    contributionsCollection(from: $from, to: $to) {
      commitContributionsByRepository(maxRepositories: 100) {
        repository { nameWithOwner }
        contributions { totalCount }
      }
      pullRequestContributionsByRepository(maxRepositories: 100) {
        repository { nameWithOwner }
        contributions { totalCount }
      }
      pullRequestReviewContributionsByRepository(maxRepositories: 100) {
        repository { nameWithOwner }
        contributions { totalCount }
      }
      issueContributionsByRepository(maxRepositories: 100) {
        repository { nameWithOwner }
        contributions { totalCount }
      }
    }
  }
}
' -F login=syntaxerror247 -F from=2025-09-16T00:00:00Z -F to=2026-09-16T23:59:59Z --jq '
.data.user.contributionsCollection
| to_entries[]
| .key as $cat
| .value[]
| select(.repository.nameWithOwner == "godotengine/godot")
| "\($cat): \(.contributions.totalCount)"
'

What this basically does is run a query through the data from the repository. 
It first looks into what one uses as filters (in this case login, from date, to date.
Afterwards it searches for what you tell it, in this case, contributions, pullRequests, pullRequestsReviews and lastly issues.
Afterwards you apply the filters. This one is searching for all of the above for user syntaxerror247, from the 16th of sept last year to 16th of sept this year.
(When I worked on this it was the 16th of september)
